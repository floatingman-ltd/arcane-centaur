== Extensions

Every extension in this configuration, with its purpose in one line. *Built here* is code written for this configuration; *Added* is every third-party plugin lazy.nvim installs. The keys each one provides are in xref:editor/keybindings.adoc[Keybindings] and the which-key popup.

[[built-here]]
=== Built here

[cols="1,3,1",options="header"]
|===
|Extension |Purpose |Guide
|`config/cheatsheet.lua` |Opens a context-aware cheatsheet and guide picker for the current filetype in a float (`<leader>?`), and renders any Markdown buffer in a popup (`:MarkdownPopup`). |xref:editor/keybindings.adoc[Keybindings]
|`config/claude_cli.lua` |Sends a selection to the `claude` CLI to suggest a shell command or explain code, and shows the answer in a float (`<leader>gcs`, `<leader>gce`). |xref:ai/ai-tools.adoc[AI Tools]
|`config/research.lua` |Asks the `claude` CLI a free-form question, either grounded in this configuration's keymaps and cheatsheets or general, and shows the answer in a float (`<leader>?l`, `<leader>?a`). |xref:ai/ai-tools.adoc[AI Tools]
|`config/lazygit.lua` + `scripts/lazygit-edit.lua` |Runs LazyGit in a floating terminal and opens files picked in it in the surrounding Neovim (`<leader>gg`, `<leader>gf`). |xref:editor/git/lazygit.adoc[LazyGit]
|`config/openspec.lua` |Runs the OpenSpec CLI from the editor to create, list and show the status of changes (`<leader>os`). |—
|`config/jira.lua` |Creates Jira Tasks and Stories from the current Markdown file or selection through the Jira Cloud REST API. |xref:tooling/jira.adoc[Jira]
|`config/confluence.lua` + `scripts/confluence_*` |Publishes a Markdown file to its Confluence page, pulls a page back to Markdown, and fetches page comments. |xref:tooling/confluence.adoc[Confluence]
|`config/marp.lua` |Exports a Markdown slide deck to PDF, HTML or PPTX and opens a live preview, using the MARP container. |xref:content/presentations.adoc[Presentations]
|`config/mdpdf.lua` |Exports Markdown to PDF with PlantUML and Mermaid diagrams rendered, using Pandoc in Docker. |xref:content/markdown.adoc[Markdown]
|`config/mdpreview.lua` |Opens the current Markdown file in the markserv container so links between pages work in the browser. |xref:content/markdown.adoc[Markdown]
|`config/http_preview.lua` |Serves generated preview HTML over `http://127.0.0.1` from Neovim itself, so sandboxed browsers that refuse `file://` can show it. |—
|AsciiDoc / Antora preview (`after/ftplugin/asciidoctor.lua`) |Renders the current AsciiDoc file, or the whole Antora site, in Docker and opens it in the browser (`,p`, `,pa`). |xref:content/asciidoc.adoc[AsciiDoc]
|PlantUML preview (`lua/plugins/plantuml.lua`) |Previews the current PlantUML diagram as an image from the local PlantUML server, or as ASCII art (`,p`, `<leader>pa`). |xref:content/diagrams.adoc[Diagrams]
|`config/lsp.lua` |Configures and starts every language server with one shared `on_attach` and shared capabilities. |xref:editor/code-intelligence.adoc[Code Intelligence]
|`config/fsharp_indent.lua` + `indent/fsharp.vim` |Gives F# indent-as-you-type, using a vendored upstream indent script with treesitter in place of its syntax lookups. |xref:languages/dotnet.adoc#fsharp-indent[.NET]
|`config/terminal.lua` |Detects the terminal emulator and exposes capability flags (Nerd Font, undercurl) so the rest of the configuration can adapt. |xref:other/terminals-ssh-tmux-mosh.adoc[Terminals]
|Terminal split, IDE layout and `:Bd` (`lua/keymaps.lua`) |Toggles a reusable terminal split (`<leader>T`), opens tree + editor + terminal in one key (`<leader>L`), and deletes a buffer without closing its window. |xref:editor/navigation.adoc[Navigation]
|which-key labels (`lua/plugins/which-key.lua`) |Labels plugin keymaps that ship without a description and names every prefix group, per filetype where a prefix means different things. |xref:editor/keybindings.adoc[Keybindings]
|`config/util.lua` |Shared helpers, such as the floating scratch window used by several of the modules above. |—
|===

[[containers]]
=== Supporting containers

Services the extensions above call, built or configured under `docker/`.

[cols="1,3",options="header"]
|===
|Container |Purpose
|`antora` |Builds this documentation site.
|`asciidoctor` |Converts AsciiDoc to HTML for the single-file preview.
|`lisp-swank` |Common Lisp REPLs (SBCL, CCL, ECL, ABCL) serving Swank on port 4005 for Conjure.
|`markserv` |Serves a directory of Markdown with working links between pages.
|`marp` |Renders MARP slide decks.
|`md2pdf` |Pandoc Lua filters that render PlantUML and Mermaid blocks during Markdown → PDF export.
|`pandoc` |Wrapper that runs `pandoc` in Docker when it is not installed, for the docs conversion scripts.
|`ollama` |Runs the local model avante.nvim talks to.
|`plantuml-server` |Renders PlantUML diagrams for previews, PDF export and Confluence.
|===
