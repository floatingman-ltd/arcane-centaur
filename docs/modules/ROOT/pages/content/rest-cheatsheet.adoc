== Running Requests

[cols=",,",options="header",]
|===
|Keys |Mode |Action
|`,r` |Normal |Run request under cursor
|`,l` |Normal |Re-run last request
|`,a` |Normal |Run all requests in the file
|`,o` |Normal |Open result pane
|`,e` |Normal |Select environment
|`,s` |Normal |Open HTTP scratchpad
|===

== Lua API

kulala.nvim at the pinned commit defines no `:Kulala` command. Call the functions directly, for example `:lua require("kulala").inspect()`. The first five are also bound to the keys above.

[cols=",",options="header",]
|===
|Function |Action
|`require("kulala").run()` |Run request under cursor
|`require("kulala").run_all()` |Run all requests in the file
|`require("kulala").replay()` |Re-run last executed request
|`require("kulala").open()` |Open result pane
|`require("kulala").scratchpad()` |Open HTTP scratchpad
|`require("kulala").inspect()` |Inspect current request
|`require("kulala").copy()` |Copy request as curl command
|`require("kulala").from_curl()` |Paste a curl command from the clipboard as a request
|`require("kulala").search()` |Search and jump to a request
|===
