== AI Tools Cheat Sheet

Covers in-editor keymaps for the *Claude CLI* (`claude`) and the
*OpenSpec* workflow tool.

*Leader* = `Space` · xref:editor/keybindings.adoc#reading-tables[Reading these tables]

== Claude Code Session (claudecode.nvim)

Persistent editor-aware session via WebSocket MCP protocol (native terminal, no snacks).

[cols=",,",options="header",]
|===
|Keys |Mode |Action
|`++<++leader++>++gcc` |Normal |Toggle Claude Code session terminal
|`++<++leader++>++gcf` |Normal |Focus session terminal
|`++<++leader++>++gcb` |Normal |Add current buffer to Claude context
|`++<++leader++>++gcv` |Visual |Send selection to Claude
|`++<++leader++>++gca` |Normal |Accept Claude's proposed diff
|`++<++leader++>++gcr` |Normal |Reject Claude's proposed diff
|===

=== Commands

[width="100%",cols="50%,50%",options="header",]
|===
|Command |Description
|`:ClaudeCode ++[++args++]++` |Toggle the session terminal (`++<++leader++>++gcc`)
|`:ClaudeCodeFocus ++[++args++]++` |Focus the terminal, or hide it if focused (`++<++leader++>++gcf`)
|`:ClaudeCodeOpen ++[++args++]++` |Open the session terminal
|`:ClaudeCodeClose` |Close the session terminal window
|`:ClaudeCodeAdd ++<++path++>++ ++[++start++]++ ++[++end++]++` |Add a file or directory, optionally a line range (`++<++leader++>++gcb` = `:ClaudeCodeAdd %`)
|`:ClaudeCodeSend` |Send the selection as an @-mention (`++<++leader++>++gcv`)
|`:ClaudeCodeTreeAdd` |Add the nvim-tree file(s) under the cursor or selection
|`:ClaudeCodeSendText++[++!++]++ ++<++text++>++` |Type text into the session and submit it (`!` = do not submit)
|`:ClaudeCodeDiffAccept` |Accept the proposed diff (`++<++leader++>++gca`)
|`:ClaudeCodeDiffDeny` |Reject the proposed diff (`++<++leader++>++gcr`)
|`:ClaudeCodeCloseAllDiffs` |Close pending diffs; accepted or saved ones stay
|`:ClaudeCodeSelectModel ++[++args++]++` |Pick a model, then open with `--model`
|`:ClaudeCodeStart` / `:ClaudeCodeStop` |Start / stop the WebSocket server
|`:ClaudeCodeStatus` |Show whether the server is running, and its port
|===

`:ClaudeCodeOpen`, `:ClaudeCodeClose`, `:ClaudeCodeTreeAdd`,
`:ClaudeCodeSendText` and `:ClaudeCodeSelectModel` exist only once the plugin
has loaded (after the first `:ClaudeCode…` command or `++<++leader++>++gc*` key).

== Claude CLI (one-shot)

These commands send the current visual selection (or whole buffer when
no selection is active) to the `claude` CLI and display the response in
a floating window.

[width="100%",cols="34%,33%,33%",options="header",]
|===
|Keys |Mode |Action
|`++<++leader++>++gcs` |Normal, Visual |Ask Claude to suggest a shell
command

|`++<++leader++>++gce` |Normal, Visual |Ask Claude to explain the
selected code
|===

=== Commands

[width="100%",cols="50%,50%",options="header",]
|===
|Command |Description
|`:ClaudeSuggest` |Send buffer/selection to `claude` for a shell
command suggestion

|`:ClaudeExplain` |Send buffer/selection to `claude` for a code
explanation
|===

=== Floating window controls

[cols=",",options="header",]
|===
|Key |Action
|`q` |Close result window
|`++<++Esc++>++` |Close result window
|===

== Research Popup

Ask a free-form question from any buffer and read the answer in a floating window.

[width="100%",cols="34%,33%,33%",options="header",]
|===
|Keys |Mode |Action
|`++<++leader++>++?l` |Normal |`:ResearchLocal` — question grounded in this config's keymaps and cheatsheets

|`++<++leader++>++?a` |Normal |`:ResearchAsk` — general-knowledge question (no local context)
|===

=== Commands

[width="100%",cols="50%,50%",options="header",]
|===
|Command |Description
|`:ResearchLocal` |Ask about this Neovim config; answer uses only local context

|`:ResearchAsk` |Ask any general question; no local context prepended
|===

Uses Claude Code's built-in auth (no `ANTHROPIC_API_KEY`). Press `q` or `++<++Esc++>++` to close the result float.

== OpenSpec

Drive the OpenSpec change workflow from within Neovim. Output is shown
in a bottom split (close with `q` or `++<++Esc++>++`).

[cols=",,",options="header",]
|===
|Keys |Mode |Action
|`++<++leader++>++osn` |Normal |Create a new change (`OpenspecNew`)
|`++<++leader++>++oss` |Normal |Show status (`OpenspecStatus`)
|`++<++leader++>++osl` |Normal |List all changes (`OpenspecList`)
|===

=== Commands

[width="100%",cols="50%,50%",options="header",]
|===
|Command |Description
|`:OpenspecNew ++[++name++]++` |Prompt for a change name (or use
argument) and create it

|`:OpenspecStatus ++[++name++]++` |Show status for all changes, or a
specific `++[++name++]++`

|`:OpenspecList` |List all changes in the repo
|===

The same workflows are available as Claude Code skills:
`/openspec-propose`, `/openspec-apply-change`,
`/openspec-continue-change`, `/openspec-verify-change`,
`/openspec-archive-change`.

== Avante AI Research

[cols=",",options="header",]
|===
|Key |Action
|`++<++leader++>++aa` |Open avante with the current provider (ollama)
|`++<++leader++>++ao` |Select the ollama provider and open avante
|`++<++C++>++s` |Submit the prompt (inside the avante input; `++<++CR++>++` = newline)
|===

=== Commands

[width="100%",cols="50%,50%",options="header",]
|===
|Command |Description
|`:AvanteAsk ++[++question++]++` |Open the sidebar; submit the question if given
|`:AvanteChat` / `:AvanteChatNew` |Open the sidebar in chat mode / start a new chat
|`:AvanteToggle` |Show or hide the sidebar
|`:AvanteFocus` |Move focus between sidebar and code window
|`:AvanteRefresh` |Redraw the sidebar
|`:AvanteHistory` |Load a saved chat
|`:AvanteClear ++[++history\|cache++]++` |Clear the current chat (default) or delete history and cache
|`:AvanteStop` |Cancel the request in flight
|`:'++<++,'++>++AvanteEdit ++[++request++]++` |Edit prompt for the selected lines
|`:AvanteBuild ++[++source=true\|false++]++` |Rerun the plugin's `make` build
|`:AvanteSwitchProvider` |Pick a provider; only `ollama` is configured
|`:AvanteModels` |Model picker; does not list `ollama`, so unused here
|`:AvanteSwitchSelectorProvider ++<++name++>++` |Set the picker backend (`native` default; fzf-lua installed)
|`:AvanteSwitchInputProvider ++<++name++>++` |Set the input backend (`native` is the only one installed)
|`:AvanteACPModels` / `:AvanteACPModes` |ACP agent model / mode; no ACP provider configured
|===

_Avante is Ollama-only; the Claude backend is disabled (Anthropic OAuth ToS) — see the guide to re-enable via API key._

_Plugin configured in `lua/plugins/avante.lua`. See xref:ai/ai-tools.adoc#avante[full Avante guide]._
