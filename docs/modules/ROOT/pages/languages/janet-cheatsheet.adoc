*LocalLeader* = `,` in Janet buffers

→ Back to xref:editor/keybindings.adoc[main cheatsheet] · xref:languages/janet.adoc[Full guide]

NOTE: This config uses the Janet *stdio client* (`janet -n -s`). Conjure spawns it automatically on first evaluation; use `,cs`/`,cS` to restart it manually.

== Structural Editing — vim-sexp-mappings-for-regular-people

[cols=",,",options="header",]
|===
|Keys |Mode |Action
|`++>++)` |Normal |*Slurp forward* — extend `)` rightward, pulling next sibling _into_ the form
|`++<++)` |Normal |*Barf forward* — shrink `)` leftward, pushing last element _out_
|`++<++(` |Normal |*Slurp backward* — extend `(` leftward
|`++>++(` |Normal |*Barf backward* — shrink `(` rightward
|`++>++e` / `++<++e` |Normal |Swap element forward / backward
|`++>++f` / `++<++f` |Normal |Swap form forward / backward
|`++<++I` / `++>++I` |Normal |Insert at head / tail of current form
|`dsf` |Normal |Splice — delete surrounding brackets
|`cse(` or `cse)` |Normal / Visual |Wrap element in `()`
|`cse++[++` or `cse++]++` |Normal / Visual |Wrap element in `++[]++`
|`cse{` or `cse}` |Normal / Visual |Wrap element in `{}`
|===

== Commands

[cols=",",options="header",]
|===
|Command |Action
|`:ConjureSchool` |Interactive Conjure tutorial
|`:ConjureEval [code]` / `:%ConjureEval` |Evaluate code / the whole buffer
|`:ConjureLogToggle` |Toggle the log window (`,lg`)
|`:ConjureJanetStart` / `:ConjureJanetStop` |Start / stop the Janet subprocess (`,cs` / `,cS`)
|`:ParinferOff` / `:ParinferOn` / `:ParinferToggle` |Parinfer in this buffer (`!` = global default)
|`:ParinferLog [file]` |Log parinfer to `file`; no argument stops logging
|`:ParinferStats` |Parinfer run-time statistics for this buffer
|===

Full list: `:help conjure` and `:help conjure-client-janet-stdio`.

== Other Active Plugins

(no keymaps; see Commands above)

(no keymaps)
* *LSP* (`janet++_++lsp`) — see lsp.md
