vim-fugitive

Run git without leaving the editor. vim-fugitive turns the ordinary git commands you already know — status, commit, blame, log, push — into editor windows you can move around in. Instead of switching to a terminal to see what changed and stage it, you open a status window, tick files off, and write your commit message in a normal buffer.

It is the tool to reach for when you want the whole picture: everything that changed, across every file, ready to stage and commit. For touching up one or two lines as you type, see gitsigns; for reading a change side by side, see diffview.

Any git command works directly as :Git <args>, or its short alias :G <args> — for example :Git commit, :G rebase -i HEAD~3.

A commit, start to finish

  1. <leader>gs — open the status window.

  2. Move to a file and press s to stage it, u to unstage.

  3. = to check the inline diff before committing.

  4. cc — write the commit message, then :wq to commit.

  5. <leader>gp — push.

Setup

Only git itself, on your $PATH:

sudo apt install git
git --version

No plugin configuration is needed. See Getting Started for the base toolchain.

In the editor, which-key shows these maps live as you type a prefix (built from each keymap’s desc), and <leader>? opens the context-aware cheatsheet. Those are the authoritative live view. Plugin configured in lua/plugins/git.lua.
