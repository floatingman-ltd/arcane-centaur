REPL — iron.nvim

REPL backend: csharprepl for C# buffers · dotnet fsi for F# buffers.

Keys Action

,sl

Send current line to REPL

,sc

Send motion or visual selection to REPL

,sp

Send current paragraph to REPL

,sf

Send entire file to REPL

,s<CR>

Send carriage return to REPL

,si

Interrupt REPL

,sq

Quit / exit REPL

,cl

Clear REPL output

[ft] defaults to the buffer’s filetype (cs or fsharp).

Command Action

:IronRepl [ft]

Open the REPL, or show / hide it if running

:IronReplHere [ft]

Open the REPL in the current window

:IronFocus [ft] / :IronHide [ft]

Jump into / close the REPL window

:IronRestart

Replace the REPL with a fresh one (no prompt)

:IronSend {text} / :IronSend! {ft} {text}

Send text to this / the ft REPL

:IronWatch file / :IronWatch mark

On write, send the file / the last-sent region

:IronAttach {ft}

Send from this buffer to the ft REPL

Debugging (nvim-dap + netcoredbg)

Prerequisites: netcoredbg (GitHub-release binary — not dotnet tool), the EasyDotnet server tool (dotnet tool install -g EasyDotnet), and fzf. Details in the .NET guide.

Keys Mode Action

<F9> or <leader>bb

Normal

Toggle breakpoint

<F5> or <leader>bc

Normal

Start or continue debugging

<F10> or <leader>bv

Normal

Step over

<F11> or <leader>bi

Normal

Step into

<F12> or <leader>bo

Normal

Step out

<S-F5> or <leader>bt

Normal

Terminate

<leader>bu

Normal

Toggle debug UI

<leader>br

Normal

Open REPL

The <leader>b mirrors exist for terminals that grab the F-keys (e.g. <F11> fullscreen).

Command Action

:DapContinue

Same as <F5>

:DapToggleBreakpoint

Same as <F9>

:DapStepOver / :DapStepInto / :DapStepOut

Same as <F10> / <F11> / <F12>

:DapTerminate

Same as <S-F5>; ends the debuggee

:DapDisconnect

Detach, leave the debuggee running

:DapNew [name…​]

Start another session

:DapPause

Pause a thread

:DapRestartFrame

Restart the current frame

:DapClearBreakpoints

Remove every breakpoint

:DapToggleRepl

Open / close the nvim-dap REPL

:DapEval[!]

Expression scratch buffer; :w evaluates (! evaluates at once)

:DapSetLogLevel {level}

Set the log level

:DapShowLog

Open the log

Testing & Running (easy-dotnet)

Keys Action

,tt

Test project (picker)

,tr

Run project (picker)

,tb

Build project (picker)

default forms ask for the project once and reuse it; :Dotnet reset forgets it. release as the first argument builds -c Release. Full list in the guide.

Command Action

:Dotnet run / run default

Run a project picked from a list / the default project

:Dotnet debug / debug attach

Debug project / attach to a process

:Dotnet watch

dotnet watch (rebuild on save)

:Dotnet build quickfix

Build, errors to the quickfix list

:Dotnet build solution

Build the solution

:Dotnet test solution

Test the solution

:Dotnet testrunner

Test runner window (<leader>r run, <leader>d debug, <leader>p stack trace, q close)

:Dotnet add package / remove package

Add / remove a NuGet package

:Dotnet outdated

Latest versions as virtual text (in .csproj); <leader>pu / <leader>pa upgrade

:Dotnet solution select

Choose the solution

:Dotnet diagnostic

Whole-solution diagnostics

:Dotnet terminal toggle

Show / hide the run/build/test terminal

:Dotnet reset

Clear remembered projects and solution
